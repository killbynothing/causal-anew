## 3. C1 Web 可视化调试控制舱 (c1_web_console)

可视化调试控制舱由极具文学极客感的前端 Bento HTML 页面与零外部依赖的 Python 后端 API 服务组成，两者基于 RESTful 架构直接交互。

### 3.1 核心功能与布局
1. **Consciousness Selector (意识读取舱)**：从下拉框中选择要测试的意识（如 `C.xiuzai.WMAIN`），系统会自动连接本地数据库展示该角色的人格核心核描述，并设置当前测试环境。
2. **FSM Console (状态机属性调节板)**：
   - 滑块调节：`Trust`、`Intimacy`、`Alert` 三个核心情感指标。
   - 变迁演算：勾选“是否包含违规行为”并点击“运行状态跃迁”后，后端自动套用 `NpcFSM` 公式计算新的属性并更改指示状态（`open`, `probing`, `guarded`, `detached`）。
   - **脱钩警告**：当状态跌入 `detached`（情感脱钩）时，控制面板会产生红色的警报闪烁，提示本状态不可逆。
3. **Retrieval & Proposition Gate (记忆检索与知识门控)**：
   - 慢环检索：输入查询词并选择情感标签，系统以条形高亮卡片展示前 2 个打分最高、带感官锚点的慢环记忆。
   - 知识门控：动态载入当前章节（1-120 可调）下该意识体的**已解锁知识**与**未解锁知识**。未解锁知识被红色高亮锁定，代表在正典中该角色绝不能知晓和泄露。
4. **Link Simulator (神经网络对话调试器)**：
   - 支持在界面配置 API Key、API URL 与 Model 名称，完美兼容 DeepSeek V4 Flash (或任何兼容 OpenAI/DeepSeek API 格式的端点)。
   - 对话发送后，系统将 System Prompt 随历史上下文传入模型，并将模型回复以 Visual Novel 气泡方式渲染（在 Canvas 小人头顶自动触发跳动动画 `talkbob`）。
   - **泄露高亮**：后端会对 AI 答复运行门控检索。如果回答中意外包含了未解锁命题的词汇，页面会拉响红色的 **`【知识泄露越界警告】`**，并指出泄露的命题 ID。
   - **数值联动**：自动解析 AI 回复中的 `Meta_State` 边车参数，如果发生了 Trust 的增减（如 `-5` 或 `+3`），会通知前端实时联动更新滑块数值与状态。

### 3.2 浏览器密码误填充 (Autofill) 修复
* **缺陷表现**：本地运行时，由于输入框为 `type="password"`，许多浏览器（Chrome / Edge 等）会强行将当前网页的物理地址 `"http://localhost:8000"` 自动填充到 API Key 框中并隐性保存，导致大模型 API 不断报错 401。
* **修复方案**：已修改 `index.html`，在此输入框中加入了 `autocomplete="new-password"`，彻底杜绝了浏览器的误填充行为。

## 4. 运行说明

1. 进入控制舱所在的新开目录：
   ```bash
   cd c1_web_console
   ```
2. 启动轻量级 API 服务：
   ```bash
   python server.py
   ```
3. 浏览器会自动弹出并打开 `http://localhost:8000`。
4. 在页面右上角 **“API 链接配置”** 填入您真实的 DeepSeek API Key 并点击保存（保存在前端 LocalStorage 中，安全无状态；也可以永久保存在 `config.json` 中）。
5. 选择角色，拉动章节滑块，输入检索词检索记忆，即可在“神经链接模拟器”中像日常终端测试一样流式和数字生命对话，并直接观测泄漏警报和状态变迁。

1. **命题 `P.GF_DEATH_TRUTH` 越界关联偏差**：
   - **问题现象**：选择意识体 `尘叔` (C.dust.W1) 时，右侧已解锁知识库中会错误展示主世界张尘的专属正典命题 `P.GF_DEATH_TRUTH`（“女友苏颖四年前在十六中正门坠楼死亡，真相为折原龙也亲手推下”）。

   - **解决方案**：后续需要修改数据库数据时，直接删除 `scripts/import_db.py` 的这三行错误关联，并对应删除角色圣经中的表格行，重新运行 `python scripts/import_db.py` 刷新数据库。
