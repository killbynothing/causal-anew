## 0. 结论

**主循环缺的不是零件，是顺序。**

四端口函数（`director_ports.py` 头注：*故意不是四次模型调用*）和整备件（`DirectorMove` / `Affordance` / `validate_director_move` / `resolve_public_action`）都在；`free_stage_prototype.py` 里也有四个落地方法（`_apply_stage_and_voice` / `_publish_dramaturgy_moves` / `_resolve_via_director_port` / `_record_director_port`）。但它们没有被一条主循环串起来：导演 LLM 仍在一份 JSON 里又写 `turns` 又报 `mh_progress`（`compact_actor_prompt` 的 `output_contract`，`free_stage_prototype.py:11786`），会计却本不该信模型。

本文件给出一拍之内：四端口按什么顺序走、闭集五招怎么出、闸怎么裁、LLM 只准填什么、进哪个现码文件。

## 2. 主循环：一拍之内四端口怎么走

```text
一拍内（生产路径统一入口）：
  输入：玩家言行 + 心想
  │
  ▼
① Resolver · 会计（确定性 · 永不 LLM）
     只认可见证据：托付出口 / 交坠 / 语言通 / 视频借出 / 收据……
     → 写 receipts / world_transactions / completed（RP3·TM2·TM3 样板函数）
     → Resolver 端口留痕
  │
  ▼
② 看见（确定性组装，无 LLM）
     账本摘要 + 脊柱剩余 + 心想(仅导演侧) + 物态
  │
  ▼
③ 出招（确定性触发 → 闭集子集）
     quiet 恒在；其余按证据触发候选
  │
  ▼
④ Resolver · 裁招（确定性 · 先于 LLM）
     逐招过闸：禁主卡台词 / 禁自报MH / 禁改正典 / 禁加入关系
     → 合法招集合（不合法 → 回 quiet）
  │
  ▼
⑤ LLM 只填（一模型一调用 · world 提示 · 不拆第二脑）
     Dramaturgy 从合法招里选一（不发明新招）
     Stage 填「场出不出手」（雨 / 吧台 / 路人，可空）
     Voice 填薄声（「好的，美式」，可空；不写世界状态）
  │
  ▼
⑥ Resolver · 复核（确定性）
     turns      → 拒收 + degradation
     mh_progress → 拒收，绝不落账
     私料 / 正典 / 关系断言 → 拒收
  │
  ▼
⑦ 落地（四端口留痕 + 可见层）
     Stage / Voice / Dramaturgy / Resolver 各记一条 director_port_trace
     主卡台词绝不来自导演 → 只由 call_actor_packet 产出
```

### 端口职责（每拍）

| 端口 | 本拍做什么 | 输入 | 输出 | LLM？ |
|---|---|---|---|---|
| **Resolver** | ①会计：MH / 交坠 / 成不成立只认可见证据；④裁招；⑥复核 | 账本 + 本拍言行/心想 | receipts / 合法招集合 / 复核结论 | **永不** |
| **Dramaturgy** | 从合法闭集里选一：时间压 / 临走窗 / 谁可进 | 合法招集合 + 看见层 | `opportunity`（不替人点头） | 可，只选合法招 |
| **Stage** | 场出不出手：雨 / 吧台 / 路人；可安静 | 看见层 | `stage` 判定（可空） | 可，可空 |
| **Voice** | 把**已成立的公共事实**译成一句可见的 | 公共事实（Stage 过滤后） | 薄声（可空） | 可，可空；**不写世界状态、不写主卡词** |

关键顺序：**Resolver 先裁，LLM 只填**。LLM 的能动性被限制在「从合法招里选 + 填字」，不是「决定这件事成不成立」。

## 3. 闭集五招（closed move set）

招名即机器 id；五招之外 LLM 不准发明新招。

| 招 | 走的端口 | 触发证据（确定性 · 看见层） | Resolver 合法前置 | 禁 |
|---|---|---|---|---|
| `quiet` 安静 | Stage（mode=quiet） | 兜底 | 恒合法 | 不出任何可见层 |
| `ambient_extra` 店员薄声 | Voice | 玩家点单 / 场内在场店员 / 时间推进 | 有店员或 `ambient_stage` 可接触人；Voice 只译已成立 | 不写主卡词；不命令店员内容 |
| `time_pressure` 时间压 | Dramaturgy→Stage/Voice | 离场窗 / `fallback_clock_active` / `stall≥阈值` / 闲聊封顶已到 | 场声明时间窗或有收束节奏 | 不报倒计时数字；不逼托付；不派词 |
| `admit_extra` 放进路人 | Stage→Voice（`ambient_actor`） | 玩家主动搭话路人 / 环顾陌生人（`player_requests_stage_improv`） | card 有 `ambient_actor_profiles` 或玩家主动要求 | 路人无包、无 Decide、无记忆核；可拒绝 |
| `close_window` 收窗 | Stage/Voice | 场收束条件接近 / 已正常道别 | 收束闸接近（如离场窗将尽） | 不替主卡做决定；不改正典 |

> 「两种演」在此分家：**角色演**（有核、有记忆、能拒绝）只走角色 Agent；**世界演**（条件变成一声/一阵）只走 Stage + Voice。店员薄声是 Voice，不是角色包——P8.1 已裁，不拆店员 Agent。

## 4. 看见层：harness 输入

| 输入 | 来源（现码） | 谁可见 |
|---|---|---|
| **账本** | `completed` / `branch_progress` / `run_observation_ledger` / `scene_receipts` / `world_transactions` | 导演全可见 |
| **脊柱剩余** | `remaining_musts` / `build_director_intents(card, completed)`；将来 `causal_web` 只读剩余节 | 导演全可见（有则给，无则空） |
| **心想** | `run_observation_ledger` private-thought 条目（`ingest_player_thought` 写入） | **仅导演侧；绝不进角色包** |
| **物态** | `body_frames` / `public_environment_deltas` / `ambient_stage` / `player_state` | 公共 / 导演 |

导演提示只喂：场框、物态、账本摘要、脊柱剩余、合法招集合。**不喂整卡 `persona_cards`**（那是角色包的事）。

## 5. 禁与闸

### 禁（四条，进合同 + 复核闸双保险）

| 禁 | 执行 |
|---|---|
| **主卡台词** | 导演输出合同无 `turns`；模型硬输出 → Resolver⑥拒收 + `degradation(director_turns_rejected)`。主卡只由 `call_actor_packet` 产出；无 speakers → 走 `ensure_solo_or_prologue_speakers`，不回退导演代写 |
| **自报 MH** | `mh_progress` 出合同；模型硬报 → 拒收，**不落账**。`completed` 只由 Resolver①证据函数写 |
| **改正典** | 导演只引用已成立公共事实（Voice）或改条件（Dramaturgy），永不写 world_truth 事实 |
| **加入关系** | Dramaturgy 只「摆出机会」，不产生任何关系/情感断言；`actor_target` 仅指已有在场者 |

### 闸（两层，都不走 LLM）

- **Resolver④ 裁招**：候选招逐条过合法前置（见 §3 表），不合 → 回 `quiet`。
- **Resolver⑥ 复核**：LLM 填完后的产物再过一遍禁清单 + 复用现有 `director_ambient_violations` / `DIRECTOR_NOTE_BANNED_PATTERNS`（禁预告、禁「完成XX」、禁姓名播报）。

## 6. 导演 LLM 合同（刀 1 的输出改动）

`compact_actor_prompt` 的 `output_contract` 在导演路径替换为：

```json
{
  "director_note": "一句只描述本拍已成立的可见事实；禁预告、禁“完成XX”、禁姓名播报",
  "opportunity": {"kind": "time_pressure | admit_extra | close_window | 空",
                  "visible_reason": "条件怎么变的", "actor_target": "可选，仅已有在场者"},
  "stage": {"active": true/false, "scene_hint": "雨 / 吧台 / 路人，可空"},
  "voice": {"text": "薄声，可空", "speaker": "店员 | 路人 | 旁白"}
}
```

- **不再有 `turns`、不再有 `mh_progress`**。
- `director_note` 保留（观测台用），但只作观察，不作旁白念给玩家。
- `ambient` 字段并入 `voice`（同一语义，字段名对齐四端口）。

## 9. 验证（刀 1 验）

- 导演 payload 含 `turns` → 拒收/丢弃 + 记 `director_turns_rejected`，四端口留痕仍在。
