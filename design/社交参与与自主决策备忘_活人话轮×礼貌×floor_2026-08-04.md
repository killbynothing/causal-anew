# 社交参与与自主决策备忘：活人话轮 × 礼貌 × floor · 2026-08-04

> **性质**：设计宪法备忘（非排期）。目标是把「角色自己想说、想做、自己决定」落成可实现的运行时原则。  
> **上位**：`角色装配备忘_用什么×怎么装×可变层_2026-08-03.md`（装什么）；本文（**怎么参与、怎么开口、谁决定**）。  
> **状态**：**现行**（2026-08-04 人裁）。实现：`runtime/social_participation.py`；天安门首发，**全场**适用原则。  
> **北极星对齐**：真造一个持续存在、会记忆、会判断、会主动行动并彼此影响的世界——机制服务于**角色活着**，不是反过来让角色完成节拍。

---

## 0. 一句话

每一拍，每个在场意识先做**自主决定**（说 / 短接 / 侧聊 / 沉默），系统只提供**世界事实、关系质地、可见场面、合法 floor**；**禁止**用待办清单、主话轮脚本、竞价加分替角色做人生规划。

## 1. 我们要解决什么（现象 → 根因）

### 1.1 人验现象（2026-08-04）

秋人开场一句叠满：听得懂日语 → 道歉 → 自报姓名 → 借视频 → 单反糊了。  
随后场面空掉，晴明（卡卡西）不接、不附和。

### 1.2 根因（机制层，不是「模型笨」）

| 层 | 现在在干什么 | 为何不像人 |
|---|---|---|
| **意图注入** | 卡 `want_now` / `goals` / `constraints` + `advance_tiananmen_want_now` 把「若听得懂则借视频」写进同一句 | LLM 按 checklist 一次勾选完；陌生人社交不会叠四个 FTA |
| **竞价修饰** | `natural_video_ask_opening`、beat 暗示等给特定 cons **内容向加分** | floor 分配器变成「任务分配器」 |
| **主/次话轮** | `primary` / `secondary` + 不同 `social_instruction` | 脚本化「主任务 / 次任务」，不是「谁此刻想开口」 |
| **输出形态** | 合法输出 ≈ 整段 `text`；沉默 = 无人 | 缺 backchannel、stage-only、侧向同伴一句；第三人「承接」无通道 |
| **must_happen** | 设计上是导演收据，运行时曾参与选说话人 / 催内容 | 收据与社交节奏混线 |

卡 `free_stage_card_tiananmen_v2.json` 的**叙事意图**其实是对的（道歉由头、聊起来才借、姓名另拍）。**运行时把顺序压扁了**。

## 2. 第一性原理：真人社交在干什么

从问题本质推，不照搬「游戏对话树」惯例。

### 2.1 三个并行过程

1. **共同注意（common ground）**  
   我们在聊什么、刚才物理上发生了什么。共同地面**逐步**建立（Clark & Brennan, 1991），不是一回合铺完。

2. **面子 / 礼貌（face-work）**  
   道歉、自报姓名、向陌生人提请求，都是 **face-threatening act（FTA）**（Brown & Levinson, 1987）。  
   - **对陌生人**：负礼貌为主——降 imposition、拆步骤、等 reciprocity。  
   - **对同伴**：可正礼貌——损友、日语拌嘴、替对方圆场（已有 Seed HOLD）。

3. **话轮 / 参与（participation）**  
   谁占 floor、谁短接、谁沉默，**局部协商**（Sacks, Schegloff & Jefferson, 1974）：  
   - 当前说话人可在 **transition-relevance place（TRP）** 让出或指定下一位；  
   - 也可无人接时自我选择；  
   - **不等于**「分数最高者拿麦」。

### 2.2 陌生人 vs 朋友（天安门场）

| | 对玩家（萍水相逢 S1） | 三人彼此之间 |
|---|---|---|
| 披露节奏 | 慢；一次一个社交动作 | 可快、可叠、可日语 side |
| 典型序列 | 蹭到 → 确认没事 →（发现语言）→ 闲聊/说明器材 → 才提请求 | 拌嘴、编排、拦漏嘴 |
| 第三人 | 短附和、可见反应即可 | 可 side remark，不必长 turn |
| 姓名 | 常在后段；可由「编排者」代为介绍 | 彼此已知，不对玩家乱报名 |

### 2.3 Goffman：参与 ≠ 只有「说话人」

**Participation framework**（Goffman, 1981；Goodwin, 2004）：

- **Ratified speaker**：占 floor 说一段。  
- **Addressed / unaddressed hearer**：听着，可 **backchannel**（嗯、没事吧、对视、点头）。  
- **Side participant**：跟同伴一句，不抢对玩家的主线。  
- **Pass**：沉默 + 可见 stage，仍是合法参与。

Bavelas 等：listener response 是**协作**——说话人寻求反馈，听众在窗口内短接，**不必换整段 turn**。

**推论**：「卡卡西不接」在真社交里往往不成立；在系统里成立，是因为**没有 backchannel 形态**。

## 3. 设计原则（宪法 · 裁后可实施）

### P1 · 自主决定，不派任务

- 系统**不**规定「本拍必须道歉 / 必须借视频 / 必须 TM2」。  
- 系统**可**维护 open concerns（未竟事），由角色**自己**决定本拍要不要推进哪一条。  
- **禁止**把多条 concern 合并进一句 `want_now` 当 checklist。

### P2 · 单 FTA 原则（陌生人）

对玩家为 **S1 陌生人** 时，若本拍为 **speak（占 floor）**，默认**只服务一个** face-sensitive 动作：  
道歉 **或** 语言发现 **或** 说明器材 **或** 一次请求 **或** 姓名相关——不叠。  
（同伴之间 side 序列不受此限。）

### P3 · Floor 与内容分离

- **Floor 分配**：谁**有资格**占一段对白（被点名、物理卷入、adjacency 义务、久未发言等）。  
- **内容生成**：占 floor 后说什么，由 **Persona × Rel × 顶格 concern × 场面事实** 决定。  
- **禁止**在竞价层做「借视频 +0.55」类 **内容 boost**。

### P4 · 参与四形态（输出类型）

每个在场意识每拍产出 **ActorDecision**（与现有 `director_intent` 对齐扩展），形态之一：

| 形态 | 可见层 | 占 floor？ | 典型 |
|---|---|---|---|
| `speak` | text (+ stage) | 是 | 对玩家一句完整话 |
| `backchannel` | 短 text 或 stage | 否 | 「嗯」「没事」+ 动作 |
| `side` | text（可标注日语） | 否 | 对同伴一句 |
| `pass` | stage / 无 | 否 | 沉默、观察 |

**串行编排**：多个 `speak` 仍串行（防合唱撞词）；`backchannel` / `stage` 可与主 speak **同拍并行**展示。

### P5 · 意图队列，不是 if-then 清单

每人维护 **open concerns**（来源：long_term_desire、scene_working_memory.unresolved、branch 事实、物理事件）：

```text
[顶格] 确认对方没被带子蹭到
[次]   对方居然听得懂日语
[次]   单反糊了，能否看看录像
[次]   自报姓名 / 等修哉编排
```

- 装配进包时：**顶格**进 `want_now`；其余进 `pending_concerns`（只读背景，不催本拍全做）。  
- 顶格被**玩家可见地解决**后 pop，下拍自然升格。  
- **不**用 `language_ok → want = 搭话并借视频` 这种合并句。

### P6 · must_happen = 导演收据，不是话轮脚本

- TM1/TM2/TM3 等：记录「可见层是否曾出现某类事实」（借视频请求是否发生过、姓名是否落地）。  
- 用于收敛、δ 账本、never_soften 相关检查。  
- **不**用于：指定说话人、本拍台词、竞价加分。  
- 收据可**晚几拍**落地，只要**顺序像人**。

### P7 · 社交习惯 = 三维质地，不是性格小作文

| 轴 | 问什么 | 例（Seed / HOLD 已有） |
|---|---|---|
| **对玩家距离** | S1 陌生人还是 S3 盟友？ | 负礼貌、单 FTA、等 reciprocity |
| **对同伴** | HOLD 边：编排 / 圆场 / 边界 | 修哉拦漏嘴、秋人实诚、晴明少占 floor |
| **参与风格** | 默认 speak 还是 backchannel？ | 晴明：多 backchannel；修哉：可 speak 可 side |

习惯写**约束怎么参与**，不写**本拍必须完成什么**。

### P8 · 导演管世界，演员管嘴

- 导演：环境、物态、非说话 NPC 行动、节拍收据、never_soften。  
- 演员：在合法参与形态下自主 decision。  
- 撞红线：剧情内收敛或物理收敛，**禁旁白硬拽**（AGENTS 红线 5）。

### P8.1 · 同拍 ambient（薄层 · 2026-08-08 人裁）

**问题**：玩家点单/环顾时，店员与雨声余波从哪来？若每职责拆一次 LLM，控场脑就碎了。

**裁决**：**不拆第二调用。** 导演同一拍 JSON 多一个可选字段 `ambient`：

| 写 | 不写 |
|---|---|
| 1 句可观察环境 / 路人 / 店员薄声（可空） | 店员 Agent / 认知环 / 独立 env LLM |
| 同拍与 `mh_progress` / `director_note` 一起出 | 把主卡台词塞进 ambient |
| look-around 无 ambient 时 → 确定性兜底句 | 环境端口再开一脑「裁决」 |

实现：`normalize_director_ambient` → narrate；`improvise_stage_environment` 仅确定性兜底。  
序幕 idle：want/concern 轻渗初遇泼袖 + 开档身份，禁简历式复述、禁编共史。

## 4. 与现有装配的关系

```text
PersonaCore + RelBaseline + ActProfile     ← 不变：谁是什么样的人
  ⊕ KnowledgeSlice + MemoryRecall          ← 不变：知道什么、想起什么
  ⊕ OpenConcernQueue（顶格 + pending）      ← 新/改：想推进什么（可变）
  ⊕ ParticipationStyle（三维质地）          ← 新/改：默认怎么参与
  ⊕ FloorEligibility（竞价结果，仅资格）    ← 改：去掉内容 boost
  ⊕ PhysicalScene + 固化事实 + BodyFrame    ← 已有
  → ActorDecision（speak | backchannel | side | pass）
```

**不改**：库真值、四支柱、固化事实进包、姓名递进绑定、观测台流水线。  
**改**：want 形态、竞价语义、输出形态、must_happen 与选角解耦。

## 6. 验收（人验 · 不是 TM 勾选率）

**天安门开场 · 陌生人线**（玩家未自报名前）：

1. **蹭到后 1–2 拍**：可见层以道歉/确认为主，**不**同句出现借视频 + 全名自我介绍。  
2. **语言发现**：像反应（「诶你能听懂？」），**不**与借视频捆在同一句。  
3. **借视频**：明显晚于「能沟通」建立；玩家说没录到则**一次收住**。  
4. **第三人**：至少一次 **backchannel 或 stage**（不是永久消失）。  
5. **修哉**：可编排、可 side，**不**包办每一句；秋人有机会自己开口。  
6. **观测台**：可见顶格 concern、参与形态、floor 资格来源；**不**用「批准旁听」类脚本。

通过标准：**像三个人带一个陌生游客**，不是 **NPC 交任务**。

## 8. 人裁结论（2026-08-04）

| # | 议题 | 裁决 |
|---|---|---|
| 1 | P2 单 FTA | **全场**全局规则（S0–S2 对陌生人）；同伴 side 不受限 |
| 2 | backchannel | **进玩家可见 text**（嗯、没事吧 等） |
| 3 | 语言呈现 | 一律中文；确认前可加（日语）；确认后不加括号、不写具体语种，有意模糊 |
| 4 | must_happen | **导演用环境/余波提示**，不派台词；收据与话轮解耦 |

| 6 | 话轮流 B | **一次只出一个气泡**；说/做输入时 **hold 队列**；说/做发送 **barge-in 截断**未播队列；心想 **不暂停** NPC |

## 9. 心想 delta 机制（导演侧 · 2026-08-04）

| 通道 | 可见性 | 写入 | 用途 |
|---|---|---|---|
| 说 / 做 | 公开 | 正常 step + 话轮流 | 社交、环境、演员 |
| 心想 | **仅导演** | `runtime/thought_delta.ingest_player_thought` → `run_observation_ledger` | 玩家推了哪些真相、关注谁、信任/怀疑 |

**分类**（启发式，非 LLM）：`player_realization`（原来/意识到…）· `player_focus`（name_book 别名）· 权重 token（龙也/修哉/挂坠/托付…带 importance）· `player_stance`（信任/怀疑）· 兜底 `player_thought`。

实现：`runtime/thought_delta.py`；仅心想时 **early return**，不跑演员 LLM。
