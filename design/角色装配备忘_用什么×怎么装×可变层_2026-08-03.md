## 0. 一句话

玩时每一拍给 LLM 的不是「一篇人设」，而是：

```text
慢变 Seed 资产（底色·关系基线·习惯倾向·知识门控·记忆库）
  ⊕ 当场装配（章/知情切片·检索到的记忆·want·情绪帧·身体帧·场次薄覆盖·导演指令）
```

**成长**发生在可变装配层与记忆增厚，不靠每章改写「他还是不是同一个人」的底色。

---

## 1. 你要齐的「角色包」≠ 全焊进「人格核」

口语里「核里要有人格、关系、习惯」——对，**角色必须有这几类资产**。  
工程上要拆开，否则成长焊死：

| 口语 | 工程名 | 可变性 | 人裁时审什么 |
|---|---|---|---|
| 人格 | **人格底色** PersonaCore | 极慢 / 不可被单次经历覆写 | 价值取向、反应模式、硬底线；**薄** |
| 关系 | **关系基线** RelBaseline + **关系状态** RelState | 基线 Seed；状态随玩/章变 | 基线：对谁是什么、义务红线；状态：亲疏/警惕档 |
| 行为习惯 | **习惯倾向** ActProfile + **身体帧** BodyFrame | 倾向 Seed；帧每拍变 | 倾向：从原著抽的类型偏好；帧：手/姿/持物 |
| 长期记忆 | **记忆库** MemoryStore → 检索 | 库增厚；单拍只进 Top-K | A 级情节基线从细剖/原著来；细节靠事件检索 |
| 此刻想要 | **want / inner** | 场次入场 → 本场/本 run 演化 | 不进永恒人格表 |
| 情绪处事 | **affect / FSM / expression** | 每拍可变 | 不进永恒人格表 |

「人格核不可覆写」（六件套）= 上表**人格底色**那一行，不是「角色所有 Seed 资产都永不改」。

---

## 2. 一拍怎么装（目标态 · 对齐初始库 §5）

```text
ActorPacket(cons, run, t) =
    PersonaCore          ← Seed 人格底色（+ 同位体共性前缀）
  ∪ RelBaseline          ← Seed 关系基线（learn_ch≤现）；RelState ← Run
  ∪ ActProfile           ← Seed 习惯倾向；BodyFrame ← Run
  ∪ KnowledgeSlice       ← Seed K.* ∩ learn_ch≤现（激活子集）
  ∪ MemoryRecall         ← slow_memory / 事件检索 Top-K（Seed∪Run）
  ∪ WantNow / working    ← Storylet 入场基线 → Run/Session 演化
  ∪ Affect / FSM         ← Run（入场可从 Storylet 种子）
  ∪ SceneThinOverlay     ← 仅本场特例（locks 本性外部分、MH 相关）
  ∪ DirectorInstruction  ← 导演本拍
```

**前台意识**：目标态按 `occupancy` + `fronting_canon` 选 cons，再装该 cons 的包。  
**呈现**：按身体。

## 3. 现况（2026-08-03 实码 · free_stage 主路径）

主路径：`/api/free_stage` → `FreeStageSession` → `build_actor_context_packet`（`runtime/free_stage_prototype.py`）→ `call_actor_packet`。  
装配实现集中在 `runtime/actor_context_v2.py`。

| 层 | 现况从哪来 | 进 LLM？ | 缺口 |
|---|---|---|---|
| 人格底色 | Seed `P.ARCH/MANNER/BOUNDARY`（+可选 VOICE）；`fetch_persona_facets` / `resolve_persona_core`；空则 `runtime/personas/*.md` | 是 | **开场二人侧已定稿向**；魏初等未做 |
| 关系基线 | Seed `REL.IDENTITY.*` + `REL.HOLD.*` 常驻投影 | 是 | **开场二人侧已齐**；RelState 仍缺 |
| 关系状态 | 卡 `fsm` / session；非 DB 关系网 | 部分 | `affect_state` 表空、未接 free_stage |
| 习惯/身体 | Seed `P.ACT.*` → `seed_acts`；session `body_frames`→`body_frame_now`；拍间 stage 回写 | 是 | 开局+结算已接；忙手禁第二物；world_truth.`body_state` 表仍未写；**观测台已投影 BodyFrame / beat_io** |
| 知识 | Seed schedule 关键词激活（人格/HOLD/IDENTITY 已排除） | 是（子集） | 与卡 `knowledge_gate` 披露并行，未统一走 `KnowledgeGateEngine` |
| 慢环记忆 | DB `slow_memory`，候选池≤64 → cue∪cos+emo 激活 Top-K | 条件是 | 龙也开场前双意识已详；装死可说闸 M2 余 |
| 情节散文记忆 | 仍多在卡 `relationship_memory` / `context_memory` | 是 | 未迁 Seed；**不得冒充全书长期记忆** |
| want | 卡 `inner_state.want_now` → session `private_inner_states` | 是 | 未进 `affect_state`；演化靠场内逻辑 |
| 前台/共驻 | 库有 `fronting_canon`/`occupancy` | **玩时不读** | 卡手写 `present`/cons |
| 场次 | 手写 `free_stage_card_*.json` | 是 | 目标：Storylet 库渲染 |

旁路（不是现玩法主路径）：

- `/api/scene`：旧薄 prompt（`scene_api`）  
- `npc_test_client.assemble`：CI/控制台系 FSM+慢环公式  
- 控制台章滑块：历史实验面，**不作为现行装配宪法**

## 4. 记忆：重大基线 vs 细节 vs 怎么装

| 级 | 是什么 | 材料来源 | 装配 |
|---|---|---|---|
| **A 重大情节基线** | 改变轨迹的经历场面（带情绪） | 原著自述/回溯 → `slow_memory` | 候选池召回；高 salience |
| **B 细节经历** | 日常/他人转述还原的行为记忆 | 同上 `slow_memory`（宜详） | **检索** Top-K；**不是**灌 `events` |
| **C 感官锚点** | 体感钩 | `slow_memory.anchor` / emo_tag | cos+emo 慢环加权 |
| **D 本周目** | 玩家造成 | run 固结 | 仅本 run |
| **开场 authored** | 咖啡馆两年等 | 标 authored；`available_ch=0` | 开场层；不称全书前史 |
| **（导演）细剖** | 世界拍进展 | `events` | **不进**角色「我记得」召回 |

> 2026-08-04：B 改口径为情景库检索；细剖归导演。龙也双意识开场前已迁库。

**序幕卡 relationship_memory ≠ 龙也全书长期记忆。** 混用即错（2026-08-03 已踩坑）。

## 5. want / 情绪 / 处事

| 东西 | 计划口径 | 现况 | 准备用 |
|---|---|---|---|
| want_now | Storylet 入场 → Run 演化；可进 ActorMind goal | 卡 + session | 维持；入库随 Storylet 迁 |
| knot / unsaid | 同 inner_state | 卡 | 同左 |
| FSM trust/intimacy/alert | 数字人六件套；表 `affect_state` | 卡拷贝进包；代数在 `npc_test_client` | 接通 Run `affect_state` + receipt |
| 处事变化 | 底色 × 知情 × 情绪 × 关系档 × 召回记忆 | 主要靠 LLM + 卡约束 | 显式 RelState + Affect，少把处事写进永恒 MANNER |
| 导演 want 压力 | director_instruction | 有 | 保持导演与演员包分离 |

## 6. 内容从哪来（铁律）

1. **原著** `source/`、**细剖/events**、已裁库行 —— 正典材料。  
2. **已人裁开场** —— 可进，必须标 `authored_*`，不得冒充原著句。  
3. **禁止**：无出处的行事偏好、用序幕散文冒充全书记忆、把场次任务写进人格底色。  
4. 行事习惯抽取：旁白 → 标动作类型 → 可选一句 exemplar + 行号（活化 §9.3）。

## 7. 以后怎么做（操作序 · 对人裁与 Agent）

1. 改角色相关能力前：读本文 §1–3，分清改的是底色 / 基线 / 可变帧。  
2. 出内容：先 ★★★ **拟入库正文**（条条出处）；Agent **自审**：出处？层放对？有没有焊死成长？  
3. **自验**：对照本文 §3 现况与目标；能指出进哪张表、哪条装配函数读它；说不清 = 不合格，**禁止端给人**。  
4. 人裁过 → 验证器 → 迁移 → `--quick`；未裁不迁。  
5. 作废件登记 INDEX，避免误迁。
