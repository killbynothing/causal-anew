## 0. 结论（先读这）

**中心医院这场成立的因果核只有一条脊柱：**

```text
海洋馆视频（被拍/发酵）
  → Cozco 认出卡卡西在北京
  → 追杀（咖啡厅狙 → … → 高速伏击）
  → 修哉/卡卡西受伤
  → 进中心医院
```

**不受伤、不进医院 → 这场没有意思。**  
奔医院的人（魏初/真纪/秋人/斑驳…）是**受伤消息的后果**，不是另立的「为什么会有这场」的因。

粒度：仍荐**中粗**，但医院段不要做成「四股独立汇流」——那是把后勤和后果误当成因。
