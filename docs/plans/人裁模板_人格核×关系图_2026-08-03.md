# 人裁模板：人格核 × 关系图（给人看的判决书）· 2026-08-03

> **用途**：凡角色人格 / 社会关系要入库，给人的可审物必须用本模板。  
> **不是给人裁的**：原著对白句清单、prop_id 目录、`--quick` 绿灯、`「玩一局自己感觉」`  alone。  
> **是给人裁的**：Agent **蒸馏写成的规格条**——LLM 演戏要吃的「怎么演 / 对谁怎么站位」。原著/细剖/库行只作**证据脚注**。

---

## 0. 分层（先分清再裁）

| 层 | 进 LLM 吗 | 人裁什么 | 不裁什么 |
|---|---|---|---|
| **人格核** | 是（短、稳、可复用） | 原则条：面具、动机轴、腔调原则、硬/软底线；**一体双魂则共性+分意识核** | 原著对白全文、语料库备份、记忆正文 |
| **关系图** | 是（按边投影；有向） | 每条边：类型、他怎么握、义务/红线、知情与披露 | 「X 是我弟弟」一句标签是否文学 |
| **知识命题 K.*** | 按 `learn_ch` 门控进包 | 是否该知道、从哪章起；**不**当人格核正文塞 | 把剧透知识写成「每天必读人设」 |
| **长期记忆** | 慢环检索注入 | 锚点清单是否够；**独立表 `slow_memory`** | 并进人格核 |
| **短期/场次** | 仅当场 | 一般**不**在人格 ★★★ 里裁 Seed | 把 want_now 写成永恒人设 |
| **场次约束** | 仅当场 | 场卡/storylet 的 must_happen；**不进**人格核 | 把一场戏的任务写成角色本性 |

**一体双魂**：两意识分核入库；玩时按 `fronting_canon` 选前台核 + 共性前缀。详见装配备忘。

**硬规则**：人格核**禁止**把原著对话整段塞给模型当样本主粮；最多允许极少条「腔调示意」（改写后的短示范，且不得泄未到章事实）。

---

## 1. 单份 ★★★ 草案必须长这样

### 文首（5 行内）

1. **对象**：`cons_id`（例：`C.ryuya.W1`）  
2. **范围**：本次只裁什么 / 明确不做的  
3. **你要回答的总问题**（一句）  
4. **现状**：库里已有薄迁移是否保留为过渡  
5. **报账**：哪里是 authored / 哪里是正典蒸馏 / 哪里空着问你  

### 人格核区（按条，不按句）

每条一个 **Facet ID**（稳定代号，便于你批「改 F3」）：

| 字段 | 含义 |
|---|---|
| Facet | 短名（例：社交面具） |
| 规格正文 | **给人/给 LLM 的蒸馏句**（原则，不是台词） |
| 证据 | 原著/细剖/库 `prop_id` / 已裁场卡（脚注级，可折叠） |
| 开场披露 | `ok_ch0` / `internal_only` / `after_ch=N` |
| 请裁 | 过 / 改（怎么改） / 否 / 缺（还要补哪一轴） |

### 关系图区（按边）

每条一个 **Edge ID**：

| 字段 | 含义 |
|---|---|
| 边 | `from → to` + 关系类型 |
| 他怎么握 | 蒸馏：情感质地、义务、禁忌 |
| 知情不对称 | 他以为对方知道什么；对方实际常不知道什么 |
| 披露政策 | 对玩家/对第三者会不会说、怎么说 |
| 证据 | 同上脚注 |
| 请裁 | 过 / 改 / 否 / 缺 |

### 文末必有

1. **已知缺口表**（原著有、本包未覆盖）——不许装齐  
2. **人裁清单**：checkbox，只问决定，不问感觉散文  
3. **入库门槛**：你点头的 Facet/Edge 才许写迁移脚本；未裁条不得进库冒充完整  

---

## 2. 你怎么批（推荐姿势）

- 先扫「规格正文」：像不像这个人、够不够演。  
- 不对就改**规格**，不要改成「把某章台词贴进来」。  
- 证据脚注只在争议时展开；证据不能代替规格。  
- 批完总裁定三选一：`整包过` / `改后过（列 Facet/Edge）` / `退回（缺轴见缺口表）`。

## 3. 与旧「★★★ 预览」的关系

| 旧预览（阶段 1–2） | 本模板 |
|---|---|
| ID 列表 +「来自卡」 | **不合格**为人裁物；仅作迁移报账附件 |
| 「玩一局判像不像」 | 降为**入库后的抽检**，不能替代本模板的事前裁 |
| 批 A 称呼表 | 降格为关系图的**薄标签层**，完整边按本模板另裁 |
