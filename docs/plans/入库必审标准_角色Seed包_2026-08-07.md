# 入库必审标准 · 角色 Seed 包 · 2026-08-07

> **性质**：人裁与 Agent 共用的**入库清单**——凡进 `world_truth.db` 的 Seed，必须按本表逐项可审。  
> **上位**：`design/角色装配备忘_用什么×怎么装×可变层_2026-08-03.md` · `筛查模板_统一格式_薄核×情景A·B×开场关系_2026-08-05.md`  
> **原则**：**关系质地 + 知情事实** 让模型自己判断怎么说；**不写**「对 X 绝口、对 Y 全说」演令。硬闸走 never_soften / canon_locked / 场级 knowledge_gate。

## 0. 你审什么（一句话）

每一角色出库一份 **★★★可审** 文档：表里每一行 = 将来 `propositions` + `knowledge_schedule`（或 `slow_memory`）的一行；**你点头的行才许 migrate**。

## 2. 可审文档固定结构（★★★可审_*）

每角色一份，文件名：`★★★可审_<角色>_全套Seed_原著细剖库_YYYY-MM-DD.md`

```text
§0  文件头（cons_id / T₀ / 状态 / 报账）
§1  库现状 vs 本稿（缺什么）
§2  参考材料索引（圣经 / 心智时间线 / 细剖 canon_locks / 旧筛查）
§3  入库预览 · PersonaCore（prop_id | statement | learn_ch | 出处）
§4  入库预览 · REL.IDENTITY + REL.HOLD
§5  入库预览 · K.*（开场 learn_ch=0 子集 + 后期寄存表）
§6  入库预览 · P.ACT.*
§7  入库预览 · slow_memory（A 桶全表；B 桶仅寄存名单）
§8  入库预览 · interaction_dynamics（新增边）
§9  情景记忆正文（§2.A 宜详；可与筛查稿合并引用）
§10 默认倾向说明（替代「披露政策」列——人读，不迁成命令）
§11 人裁 checkbox + 入库脚本名（待写）
```

登记：`docs/plans/INDEX.md`。

## 3. 列口径：默认倾向（人审用，不迁入 proposition）

| 倾向 | 含义 | 入库写什么 |
|---|---|---|
| **可轻提** | 闲聊可能主动带出 | 记忆 `projection_text` 或 REL 质地 |
| **仅被问可答** | 追问才说，且选段 | K.* + 记忆；不写「必须答」 |
| **internal** | 内心有，不对当前对象主动展开 | 只进记忆/ K.*，不进 HOLD 命令 |
| **不主动提** | 默认不开口（模型自判） | **知情不对称** 写进 REL 或 K.asym.* |

**禁止迁入**：「绝口」「禁止对魏初说 X」；**禁止否定式入库**（「不知」「对方不知」「未识」）—— asym 由模型从「我知道…」+ 关系质地自推。

### 人格核 vs 关系 vs 知识（张尘级复杂角色）

| 进 PersonaCore | 进 REL | 进 K.* |
|---|---|---|
| 任何时候都这样：善良、疲惫、承担、策划煽动、多层身份结构 | 对**具体某人**是谁、怎么握（魏初/龙也/周泽…） | RTW/世府/尘叔/DS/LT/跃迁**他知道的事实** |
| 屌丝无害是**面具原则**，不是某场入职情节 | T₀ 未建立的关系 **不写边**（卡卡西/修哉） | 心智时间线 K0–K4；试写版「暴露层级 L0–L4」作行为原则可进 MANNER |
| 洋葱式选择性露出是**处事方式** | 入职/大冒险等 **场面 → slow_memory** | |

## 4. 材料优先级（参考旧库）

| 优先级 | 材料 | 用途 |
|---|---|---|
| 1 | `source/novel_*.md` 行号 | 唯一正典出处 |

| 4 | 旧仓 `analysis/时间线/*心智*` | 开场前 K0 命题清单 |
| 5 | `docs/plans/★★★筛查_*` | 情景 A/B 正文（宜详） |
| 6 | authored 开场 | 标 `authored_*`；不得冒充原著句 |

## 5. 入库门槛（Agent 自验 · 你过闸）

- [ ] 每行有 **prop_id / mem anchor / 出处**（推断标 ★待核，不 silent 删）
- [ ] 人格核 **≤7**（张尘类多重身份可 §1 分面，但迁库仍映射到 P.ARCH/MANNER/BOUNDARY）
- [ ] REL 边 = **事实 + 质地**；无逐人演令
- [ ] A 桶记忆 **条数只增不减**；B 桶不混入 A
- [ ] **本世界张尘无跃迁自体验**（尘叔/LT 另册）
- [ ] 可指出每行进哪张表、哪条装配函数读它
- [ ] 人裁点头前：**禁止** `--apply` migrate
