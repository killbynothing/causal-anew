## 1. 怎么安进去（目标装配）

### 1.1 三层各吃各的

```text
人格核 PersonaCore          ← 薄、慢变、不可被单次经历覆写
知情切片 KnowledgeSlice     ← 「知道什么」结论/版本（semantic）
情景记忆 EpisodicRecall     ← 「想起哪几场」带情绪（本策划主菜）
本场/本 run                 ← want、固化、场次散文（薄覆盖）
```

**禁止**：用人格核句冒充记忆；用 `events` action 灌进「我记得」；用序幕卡 `relationship_memory` 冒充全书记忆库。

### 1.2 一条情景记忆长什么样（入库单位）

落表现行表 **`slow_memory`**（可加列，见 §3；未裁不改 schema）。

| 字段 | 必填？ | 含义 |
|---|---|---|
| `cons_id` | 是 | 绑**意识**（龙也 = `C.ryuya.W1` / `C.ryuya.WMAIN` 分册） |
| `text` | 是 | **经历正文**：谁·哪·做了什么·当时感觉（第一人称可回忆口吻，非人设形容词堆） |
| `emo_tag` | 是 | 情绪标签（与召回 β 匹配） |
| `anchor` | 是 | 感官/场面钩（金属凉、枪托、电梯提示词…） |
| `salience` | 是 | 显著性 0–1（重大基线高） |
| `available_ch` | 是 | 从哪章起「持有」（开场前 = 0）；**禁止孤儿行** |
| `reveal_ch` | 可选 | 可对玩家说破的章；未到则只用 `projection_text` 或不进可说层 |
| `projection_text` | 可选 | 未到 reveal 时的安全说法 |
| `src_event` | 可选 | 能挂细剖则挂；纯前史可空，但必须有 `available_ch` + `canon_src`（出处进 migrate 日志/命题脚注） |
| `run` | 是 | Seed=0；本周目追加 ≥1 |
| `speak_policy` | ★建议 | `never` / `ask_only` / `opening_whitelist` / `free_after_reveal`（可先放 JSON 扩展或平行表） |

双魂：**同一世界事件两条（或两 View）**，不可共用一条糊过去。

### 1.3 一拍怎么装进包（运行时）

主路径已有钩子：`build_actor_context_packet` → `fetch_slow_memory` → `activate_memory_candidates` →（开场顶配）`score_slow_memory_cos_emo` → `self_memory.slow_memory_top_k`。

**目标规程（写死）：**

```text
1. Fetch：cons + run∈{0,run} + available_ch≤ch   → 候选全集（可详，不截成「整库只有5条」逻辑误伤）
2. Score：α·sim(q, text+anchor) + β·emo_match(affect_now) + γ·salience
         （开场顶配已有 cos+emo；推广为 free_stage 默认）
3. Gate：speak_policy × disclosure × 装死危险闸 × 关系档
         → 进「可想」vs「可说」两栏（观测台都要看见）
4. Inject：Top-K（建议想≤4、说≤2）进 ActorPacket.self_memory
5. 禁止：对白检索 events；禁止把未激活候选整表塞 prompt
```

**与知情层分工**：K.* / lorebook keyed 回答「你知不知道」；情景记忆回答「你想起哪一幕」。可同拍并存，观测台分栏。

### 1.4 安进 prompt 的形状（给演员看的）

```text
【本拍想起】
- [W1-M6] 每一次跳转都要念完「电梯即将向上」才敢闭眼…（emo=麻木仪式）
- [W1-M12] 街角咖啡馆那次泼袖…（emo=熟络）
【本拍不可说破】（系统闸，不念给玩家）
- 跃迁/尘叔/弑父…（列出 mem_id）
```

导演包**不**吃角色情景全文；导演吃 `events` 章窗 + 场面义务。

## 2. 内容怎么进库（蒸馏流水线）

### 2.1 材料三类（已裁）

1. **自述章**（龙也 Ch.110 / 跃迁自述）  
2. **事件实行**（他做了什么）  
3. **他人转述→他的行为**（真纪/魏初/张尘…还原成他侧经历）

另：authored 开场（标私设）；尘叔旁证可作脚注，不代替 W1 自述。

### 2.2 操作序（每个角色 / 每个意识）

| 步 | 产出 | 谁验收 |
|---|---|---|
| S1 筛查表 | ID · 场面摘要 · emo · 出处行号 · 开场可说？ · 归属 cons | 人扫一眼 |
| S2 拟入库正文 | 每条完整 `text` + 全字段 + 报账「哪是 authored」 | ★★★ 人裁 |
| S3 自验 | 层对？双魂分清？孤儿行？装死闸？ | Agent 门；不过不上桌 |
| S4 迁移脚本 | `migrate_*_episodic_*.py --apply` | `--quick` 绿 |
| S5 实机 | 观测台：候选/激活/为何挡；玩时抽问 | 人验 |

**底库不砍。** 灌包用 Top-K。

### 2.3 龙也竖切（第一刀内容）

- 已有：筛查改2（W1-M1…M13 / WM-M1…M16 + 人裁白名单）。  
- 下一刀：S2 拟入库正文（先 W1 跃迁根基 W1-M5–M11 + 开场可演 M12–M13；并行 WMAIN 脏活与自述）。  
- 开场可说白名单（已裁）：有弟弟；已婚（不露是谁）；咖啡馆层；其余绝口。

## 3. 工程怎么接（具体执行）

### Loop 定义总闸

| 项 | 内容 |
|---|---|
| **目标** | 情景记忆：蒸馏入库 → fetch 无孤儿 → cos+emo Top-K 进包 → 披露闸可观测；龙也双意识开场竖切可人验 |
| **边界** | 不改人格核当记忆；不玩时搜 events/原著；不砍底库充绿；未裁不迁；不 force-push |
| **降级** | schema 来不及加 `speak_policy` 列 → 用 `projection_text`+卡 disclosure 先撑；P2 独立表后置 |
| **验证** | 见各 Loop；收尾 `--quick` 必绿 |
| **心跳** | 观测台三栏：持有数 / 本拍激活 / 本拍挡说 |
| **做-验分开** | 写迁移的不自裁内容；内容人裁；行为另一测或人玩 |

### Loop M0 · 口径落文档（零代码）

- 人裁通过本文 §1 + 装配备忘 §4 改写草案（情景主粮；events 导演）。  
- 验证：文档 diff 你点头。  
- **你现在看的就是 M0 待裁件。**

### Loop M1 · schema 纪律 + 验证器（先于大宗内容）

- 断言：`slow_memory` 无「无 src_event 且无 available_ch」孤儿。  
- 现有孤儿行：补 `available_ch` 或删（按已裁清单，如 poetic 已删类）。  
- 验证：`test_slow_memory_no_orphans.py` 红→绿。  
- **可与两场收口并行。**

### Loop M2 · 召回接线（free_stage 默认）

- `fetch_slow_memory`：候选按 cons 全量符合章窗（去掉误伤的过早 `[:top_k]` 截断，或改为「候选上限」与「激活 Top-K」分离）。  
- 激活：cue ∪ cos+emo（开场顶配公式推广）；写入 `activation_reason`。  
- 披露：接开场白名单 / `never`；装死危险闸（家人具体身份）。  
- 观测台：持有 / 激活 / 挡说。  
- 验证：`test_episodic_recall_opening_ryuya.py`（提到弟弟≠展开弑父；跃迁候选可持有但不进可说）。

### Loop M3 · 龙也拟入库正文 ★★★

- 按筛查 ID 出全文；报账 authored。  
- 你点头 → M4。

### Loop M4 · 迁移入库

- `scripts/migrate_ryuya_episodic_deep_past_*.py`  
- 双意识分行；`available_ch=0`；W1 跃迁条 salience 高。  
- 验证：条数断言 + 双魂不对齐单测 + `--quick`。

### Loop M5 · 人验

- 序幕：闲聊不泄家；托付拍全名；交坠。  
- 观测台：跃迁条在「持有/挡说」，咖啡馆在「可想/可说」。  
- 抽问「结婚了吗」→ 已婚匿名；「妻子是谁」→ 不答具体。

### Loop M6 · 复制管线（后置）

- 天安门四人 / 魏初：同一 S1→S5；不阻塞龙也竖切。

## 4. 与现码对照（改哪里）

| 现况 | 目标 |
|---|---|
| `fetch_slow_memory` 末尾 `[:top_k]` 易误伤候选 | 候选与激活 Top-K 分离 |
| 激活偏 cue；cos+emo 仅 opening_top_tier | free_stage 默认 cos+emo+cue |
| 多数 slow_memory 孤儿 | M1 清污 + 新行纪律 |
| 卡 `relationship_memory` 散文 | 降为场次薄层；全书经历进 `slow_memory` |
| lorebook keyed | 过渡；入库后同内容归记忆/知情，去双源 |
| `events` 同章投影 | 保持导演通道，不进情景召回 |

关键文件：`runtime/actor_context_v2.py`、`runtime/opening_top_tier.py`、`runtime/free_stage_prototype.py`（`build_actor_context_packet`）、`c1_web_console` 观测台记忆栏。
