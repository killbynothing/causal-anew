## 3. 刀序

### 刀 A · Rubric `--smoke`（先）

- **做**：`runtime/narrative_rubric.py` + `scripts/eval_narrative_rubric.py`。黄金集=内置 badcase（泄密、读心、非法招、复读），不编正典。  
- **验**：`python scripts/eval_narrative_rubric.py --smoke`；单测进 `--quick`。

### 刀 B · 导演五招 = Function Calling

- **做**：`runtime/director_tools.py`。五招 JSON schema；`parse_tool_call` 调 `adjudicate_move`。非法名 / 本拍不合法 / 多余字段 → 拒。不改导演 LLM 合同。  
- **验**：`scripts/tests/test_director_tools.py`。

### 刀 C · 观测台七槽

- **做**：`runtime/agent_module_slots.py` 从 `debug_payload` 投影七槽；`observer.html` ④ 组加一排只读槽。不改 Decide/Enact/Reflect。  
- **验**：投影单测；观测台打开一场能看见七个名字有值或「—」。

### 刀 D · 对齐旁路

- **做**：`scripts/pipeline/build_preference_pairs.py`。正例=角色包短句口径；负例=导演代写 / 客服腔 / 剧透 / 读心 / 复读（机制夹具，非新正典）。可选 `scripts/eval_preference_head.py`（torch 才训小头）。  
- **验**：jsonl schema 单测；无 torch → SKIP。`--dry-run` 不准假装训过。

刀 A–C 投递前必绿。刀 D 有 jsonl 即可在仓外简历写「对齐数据闭环」。人验与刀 6 并行，不挡 A–C。

**2026-09-18 落地**：刀 A–D 机制完，进 `--quick`。人验仍待你。
